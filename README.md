# CR Elixir Tracker (Android)

Оверлей для Clash Royale: еліксир суперника, його колода (до 8 карт) і цикл карт.
Показується **тільки поверх Clash Royale** (визначає активний застосунок через Accessibility Service, вміст екрана не читає).

Готовий APK: [`release/cr-elixir-tracker.apk`](release/cr-elixir-tracker.apk) (Android 8+, targetSdk 34 — підходить для Samsung Galaxy A52 на Android 13/14).

## Встановлення
1. Скачай APK на телефон, відкрий, дозволь встановлення з цього джерела.
2. Android 13+: *Налаштування → Програми → CR Elixir Tracker → ⋮ → Дозволити обмежені налаштування* (кнопка «Інформація про застосунок» у додатку веде туди).
3. *Спеціальні можливості → Встановлені застосунки → CR Elixir Tracker →* увімкнути.
4. Запусти Clash Royale — оверлей з'явиться сам і зникне при виході з гри.

## У бою
- **▶** на старті бою (таймер 3:00). Еліксир стартує з 5, реген 1 / 2.8 с; x2 з 2:00, x3 з 4:00 (пізній овертайм). Тап по таймеру — ручний режим авто/x1/x2/x3.
- Суперник зіграв карту → тап по її слоту, або **+ карта** / **?** → вкладка вартості → карта. Перша зіграна карта автоматично запускає таймер.
- Слоти: зелений ✓ — у руці, жовтий **1** — наступна в руку, сірий **2–4** — черга. Рядок «Далі» — порядок повернення карт.
- Mirror = вартість попередньої карти + 1. **⚡** — здібність чемпіона. **+1/−1** — корекція (Elixir Collector і т.п.).
- **↶** — undo, **⟲** (утримання) — новий бій, **–** — згорнути, **⠿** — перетягнути.
- Якщо карта дорожча за еліксир у трекері — еліксир обнуляється (автокалібрування).

Точність залежить від того, наскільки вчасно натиснуто ▶ і зареєстровано карти: автоматичного розпізнавання екрана немає.

## Збірка
```
sudo apt install aapt dalvik-exchange zipalign apksigner
ANDROID_JAR=/path/to/android-34/android.jar tools/build.sh
```
Скрипт проганяє JVM-тести логіки (`TrackerTest`) і збирає `app/build/cr-elixir-tracker.apk`, підписаний ключем із `keystore/` (пароль `android`).

Вартості карт — у `Card.java`; після балансних змін їх можна підправити там.
