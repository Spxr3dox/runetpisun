# Gemini Кнопка (iOS, iPhone 15)

Затискаєш кнопку → відкривається Gemini.
- Є застосунок **Google Gemini** → відкривається він (вхід у Google-акаунт уже там).
- Нема → відкривається gemini.google.com з входом через Google-акаунт (сесія запам'ятовується).

## Як отримати «кнопку» як на Samsung
iOS не дає змінити бокову кнопку (довге натискання = Siri), а на iPhone 15 (не Pro) немає Action Button.
Найближчий аналог — **Торкання ззаду**:
1. **Команди** → «+» → Додати дію → **Gemini Кнопка → Викликати Gemini** → зберегти.
2. **Параметри → Доступність → Дотик → Торкання ззаду → Двічі** → вибрати цю команду.

Подвійний тап по спинці → Gemini. У програмі: кнопка з утриманням (0.2–1.5 с) і опція «відкривати Gemini одразу при запуску».

## Встановлення .ipa
Готовий файл — `GeminiButton-unsigned.ipa` у [Releases](../../releases) (збирається GitHub Actions).
Apple не дозволяє ставити непідписані програми, тому підпиши своїм Apple ID:
1. Комп'ютер (Windows/Mac) → [Sideloadly](https://sideloadly.io) → підключи iPhone кабелем.
2. Перетягни `.ipa`, введи Apple ID → Start.
3. iPhone: **Параметри → Загальні → VPN і керування пристроєм** → довіряти своєму Apple ID;
   **Параметри → Конфіденційність і безпека → Режим розробника** → увімкнути.

Безкоштовний Apple ID: підпис діє 7 днів, потім повтори крок 2 (або AltStore оновлює сам).

## Збірка вручну (Mac)
```
brew install xcodegen
cd ios-gemini-button && xcodegen generate && open GeminiButton.xcodeproj
```
Вибери свою Team у Signing і запусти на iPhone.
